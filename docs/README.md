# بازی رمز و راز؛ راهنمای اسناد

یک بازی معمایی مرحله‌ای برای Android، افقی و فقط فارسی، در سبک Brain Test / Brain Out. هر مرحله یک سؤال کوتاه، صحنه و اشیای قابل تعامل دارد؛ بازیکن پاسخ را در صحنه انجام می‌دهد و معمولاً نیازی به تایپ یا انتخاب گزینه ندارد. راه‌حل پس از کشف باید ساده و قابل فهم باشد و اثر حرکت درست را در صحنه نشان دهد.

قالب مشترک مرحله شامل سؤال، اشیا و دام‌ها، واکنش به تعامل، شرط برد و نتیجه است. محتوا همراه برنامه منتشر می‌شود. این سند معرفی محصول و فهرست مراجع است؛ جزئیات قواعد در مرجع تخصصی نگهداری می‌شود.

## مسیر تولید

سناریو از جدول محتوا انتخاب شود؛ داده و قوانین طبق قرارداد موتور، منابع طبق قواعد پروژه و چیدمان طبق قواعد موبایل ساخته شوند. موتور و UI مشترک بمانند و منطق اختصاصی فقط برای نیاز واقعی سناریو اضافه شود. وضعیت آماده‌بودن و پذیرش از برنامه و شواهد توسعه خوانده شود؛ معرفی یک سناریو به‌تنهایی به‌معنای پیاده‌سازی یا تأیید آن نیست.
